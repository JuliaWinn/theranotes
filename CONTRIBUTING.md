# Contributing

Corrections to transcripts and citations are especially useful. Include the conversation URL or record ID, the exhibit and PDF page, and your proposed correction. Keep source text separate from interpretation.

For code changes, follow the local setup in the README. Preserve static reading without JavaScript, existing URLs and legacy bookmarks, source citations, and production-only GoatCounter tracking. Run the data checks, build, tests, and format checks before proposing a change.

Do not add downloaded research archives, raw OCR, unredacted originals, credentials, local account screenshots, or generated build output. Public files are explicitly listed in `repository-files.txt`; see `docs/development.md` before adding files.
